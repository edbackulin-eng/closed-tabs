# Music licences

Every track is by Kevin MacLeod (incompetech.com) under Creative Commons
Attribution 4.0, which allows commercial use, including monetised YouTube, on
condition of credit. The same source and terms as the What If channel.

Credit line required in the description of every video that uses a track:

    <Title> by Kevin MacLeod (incompetech.com)
    Licensed under Creative Commons: By Attribution 4.0
    https://creativecommons.org/licenses/by/4.0/

The pipeline writes these lines into each description automatically, for exactly
the tracks used, from `assets/music/library.json`. The mp3s are not stored in
this repository; they are fetched from the URLs below on the runner.
