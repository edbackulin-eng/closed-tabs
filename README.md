# Closed Tabs

Automated English-language channel about real internet mysteries: puzzle hunts,
alternate reality games, lost media, strange channels and broadcasts, internet
folklore. Every script is written only from at least two open sources, which are
listed in the video description.

Out of scope, always: real deaths or suicides, victims of crimes, private
individuals, minors, active criminal cases, graphic detail.

Code only. Keys live in GitHub Secrets; media is gitignored, and
`scripts/check_repo.py` refuses any commit or push carrying a token or a file
over 5 MB.
